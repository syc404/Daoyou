如何开始游戏？

点击“开始游戏”进入游戏站，使用邮箱验证码或邮箱密码注册、登录，再按游戏内引导创建角色。本站前端提供邮箱登录入口。

需要下载客户端吗？

不需要。使用电脑或手机浏览器即可游玩，同一个账号可以在不同设备登录。

AI 会决定所有游戏结果吗？

角色设定和部分叙事会使用 AI 生成。战斗、资源消耗与奖励由游戏规则结算；实际开放内容以游戏内为准。

账号、角色和游戏问题找谁处理？

本站独立维护。如遇登录、邮件验证或存档问题，可通过 game@hantieyi.cn 联系本站。请勿发送密码、验证码或 API Key。

这个站点与开源项目是什么关系？

本站基于 ChurchTao / Daoyou 开源项目修改并独立运营。项目采用 GPL-3.0 许可证；本站维护方负责本站账号与游戏服务。获取本站版本对应源码，也可在页脚查看项目来源及许可证。
